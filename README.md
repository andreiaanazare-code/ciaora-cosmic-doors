# CIAORA — The Invitation · edição visual premium

Esta edição inclui a imagem visual aprovada e os quatro vídeos originais da prévia anterior. O filme abre pelo botão «VER O FILME» e regressa às quatro portas no final. A montagem dos quatro clips é uma prévia, não o storyboard final de 16 cenas. As portas não têm URLs inventados: os destinos devem ser confirmados antes da ligação.

Para publicar em GitHub Pages, extrai este ZIP e coloca **o conteúdo da pasta** na raiz do repositório (incluindo `assets/`); não publiques apenas o ZIP. Em Settings → Pages, escolhe Deploy from a branch, `main`, `/ (root)`.
