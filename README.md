# CIAORA — The Invitation
Prévia autónoma para GitHub Pages usando os clips originais fornecidos. Abre `index.html` para pré-visualizar. Publicação: enviar todos os ficheiros para a raiz do repositório e ativar GitHub Pages em Settings → Pages → Deploy from a branch → main / root. Os quatro vídeos originais são reproduzidos em sequência; não são apresentados como a montagem final aprovada. Os destinos das portas permanecem intencionalmente desativados até haver URLs confirmados; preencher `destinations` em `index.html` para os ativar. O código original do projeto Lovable Cosmic Doors não foi modificado nem transferido para este pacote.
